# 2048 Game Documentation

2048 is a numerical puzzle game where the player combines tiles with the same numbers to reach the 2048 tile.

## Technical Implementation

### 1. Data Structure (`src/app/game/2048/page.tsx`)
Tiles are stored as an array of `Tile` objects:
```typescript
type Tile = {
  id: number;      // Unique ID for animations
  value: number;   // Numerical value of the tile
  row: number;     // Row index (0-3)
  col: number;     // Column index (0-3)
};
```

### 2. Movement Logic (`move` function)
The `move` function handles the sliding and merging of tiles:
- Tiles are sorted based on the movement direction to ensure correct processing order.
- Each tile moves until it hits the edge of the grid or another tile.
- If two tiles with the same value collide, they merge, and the player's score increases.
- After a successful move, a new tile (2 or 4) is spawned in a random empty position.

### 3. Animations
`framer-motion` is used to create smooth animations:
- `layoutId`: Enables smooth transitions of tiles between different positions.
- `initial` and `animate`: Handles the scale-up animation for new tiles.
- `AnimatePresence`: Manages the exit animations for merged tiles.

### 4. Controls
Players can use the **Arrow Keys** or **WASD** keys to play the game.

## Features
- **Scoring**: Tracks current score and high score (saved in `localStorage`).
- **Game Over**: Displays a "Game Over" overlay when no more moves are possible.
- **Win State**: Displays a victory message when a 2048 tile is created.
- **Modern Design**: Utilizes a color palette consistent with the app's theme and visual effects.
