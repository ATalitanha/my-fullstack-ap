# Internationalization (i18n) Documentation

This section is responsible for managing the multi-language support (Persian and English) of the application.

## Core Components

### 1. `LanguageContext.js`
Located at `src/constants/LanguageContext.js`, this file handles the core language management logic.
- **Key Functions**:
  - `changeLanguage(newLang)`: Changes the current application language and loads the corresponding dictionary.
  - `t(key, params)`: The main translation function that takes a key (e.g., `app.main.welcome`) and returns the translated value.
  - `formatNumber(number)`: Formats numbers based on the current language (e.g., converting English digits to Persian digits).
- **Storage**: The selected language is saved in `localStorage` to persist across sessions.

### 2. Dictionaries
The files `src/dictionaries/fa.json` and `src/dictionaries/en.json` contain all the application text. They follow a nested structure for easier management.

### 3. `useTranslation` Hook
Defined in `src/hooks/useLanguage.js`, this hook provides a convenient interface for using translations within components.
- **Usage**:
  ```javascript
  const { t } = useTranslation("app.messenger");
  return <h1>{t("title")}</h1>; // Automatically resolves to app.messenger.title
  ```

## Adding a New Language
To add a new language:
1. Add the language code to `SUPPORTED_LANGUAGES` in `LanguageContext.js`.
2. Create the corresponding JSON file in the `dictionaries` folder.
3. Update the `getDictionary` function in `src/lib/dictionaries.js`.
