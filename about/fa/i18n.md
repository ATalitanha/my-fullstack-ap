# مستندات بخش بین‌المللی‌سازی (i18n)

این بخش مسئول مدیریت چندزبانه بودن اپلیکیشن (فارسی و انگلیسی) است.

## اجزای اصلی

### 1. `LanguageContext.js`
این فایل در مسیر `src/constants/LanguageContext.js` قرار دارد و منطق اصلی مدیریت زبان را بر عهده دارد.
- **توابع مهم**:
  - `changeLanguage(newLang)`: زبان فعلی اپلیکیشن را تغییر داده و دیکشنری مربوطه را بارگذاری می‌کند.
  - `t(key, params)`: تابع اصلی ترجمه که یک کلید (مانند `app.main.welcome`) را دریافت کرده و مقدار ترجمه شده را برمی‌گرداند.
  - `formatNumber(number)`: اعداد را بر اساس زبان فعلی فرمت‌دهی می‌کند (تبدیل اعداد انگلیسی به فارسی در زبان فا).
- **ذخیره‌سازی**: زبان انتخاب شده در `localStorage` ذخیره می‌شود تا در مراجعات بعدی حفظ شود.

### 2. دیکشنری‌ها
فایل‌های `src/dictionaries/fa.json` و `src/dictionaries/en.json` شامل تمام متن‌های اپلیکیشن هستند. ساختار این فایل‌ها به صورت درختی است تا مدیریت آن‌ها آسان‌تر باشد.

### 3. هوک `useTranslation`
این هوک در `src/hooks/useLanguage.js` تعریف شده و رابط کاربری راحتی برای استفاده از ترجمه‌ها در کامپوننت‌ها فراهم می‌کند.
- **نحوه استفاده**:
  ```javascript
  const { t } = useTranslation("app.messenger");
  return <h1>{t("title")}</h1>; // به صورت خودکار app.messenger.title را پیدا می‌کند
  ```

## افزودن زبان جدید
برای افزودن یک زبان جدید:
1. کد زبان را در `SUPPORTED_LANGUAGES` در فایل `LanguageContext.js` اضافه کنید.
2. فایل JSON مربوطه را در پوشه `dictionaries` بسازید.
3. تابع `getDictionary` را در `src/lib/dictionaries.js` بروزرسانی کنید.
