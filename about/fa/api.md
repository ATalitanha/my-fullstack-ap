# مستندات APIها

این سند به بررسی Endpointهای موجود در پروژه می‌پردازد.

## 1. احراز هویت (`/api/auth`)

- **`POST /api/auth/signup`**:
  - ورودی: `username`, `email`, `password`.
  - عملکرد: ایجاد کاربر جدید در دیتابیس با رمز عبور هش شده.
- **`POST /api/auth/login`**:
  - عملکرد: احراز هویت و تنظیم کوکی‌های JWT.
- **`GET /api/auth/refresh`**:
  - عملکرد: تمدید Access Token با استفاده از Refresh Token.
- **`POST /api/auth/logout`**:
  - عملکرد: پاک کردن کوکی‌های احراز هویت.

## 2. یادداشت‌ها و کارها (`/api/notes`, `/api/todo`)

هر دو از الگوی مشابهی پیروی می‌کنند:
- **`GET`**: دریافت لیست آیتم‌های متعلق به کاربر وارد شده.
- **`POST`**: ایجاد آیتم جدید.
- **`PUT /id`**: بروزرسانی آیتم موجود.
- **`DELETE /id`**: حذف آیتم.

## 3. پیام‌رسان (`/api/massage`)

- **`GET`**: دریافت تمام پیام‌های عمومی.
- **`POST`**: ارسال پیام جدید.
- **`DELETE`**: حذف پیام (تکی با ID یا تمام پیام‌ها با پارامتر `deleteAll`).

## 4. تاریخچه ماشین‌حساب (`/api/history`, `/api/adhistory`)

ذخیره و بازیابی محاسبات انجام شده توسط کاربران برای نمایش در بخش "تاریخچه".
- **`POST`**: ذخیره عبارت (`expr`) و نتیجه (`result`).
- **`GET`**: دریافت لیست آخرین محاسبات.
- **`DELETE`**: پاک‌سازی تاریخچه.
