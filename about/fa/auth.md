# سیستم احراز هویت و امنیت

TanhaApp از یک سیستم احراز هویت مبتنی بر Token (JWT) برای محافظت از داده‌های کاربران استفاده می‌کند.

## اجزای سیستم

### 1. ثبت‌نام و ورود (`/signup`, `/login`)
- **رمزنگاری**: رمزهای عبور کاربران قبل از ذخیره در پایگاه داده، با استفاده از `bcrypt` هش می‌شوند.
- **اعتبارسنجی**: ایمیل و نام کاربری باید یکتا باشند.

### 2. مدیریت توکن‌ها (JWT)
- **Access Token**: یک توکن کوتاه‌مدت برای دسترسی به APIهای محافظت شده.
- **Refresh Token**: ذخیره شده در کوکی‌های امن (HttpOnly) برای تمدید خودکار دسترسی بدون نیاز به ورود مجدد کاربر.

### 3. APIهای محافظت شده
توابع واسط (Middleware) یا توابع کمکی مانند `verifyToken` در `src/shared/lib/auth.ts` برای بررسی معتبر بودن توکن در درخواست‌های API استفاده می‌شوند.

## ساختار پوشه‌بندی مرتبط
- `src/app/api/auth`: شامل Routeهای ثبت‌نام، ورود، خروج و تازه‌سازی توکن.
- `src/shared/hooks/useAuth.ts`: هوک سفارشی برای مدیریت وضعیت ورود کاربر در سمت کلاینت.
- `src/app/dashboard`: صفحه‌ای که تنها برای کاربران وارد شده قابل دسترسی است.

## نکات امنیتی پیاده‌سازی شده
- استفاده از کوکی‌های **HttpOnly** برای جلوگیری از حملات XSS.
- هش کردن رمزهای عبور با Salt مناسب.
- استفاده از **Zod** برای جلوگیری از ورود داده‌های مخرب به APIها.
- محافظت از مسیرهای حساس در سمت سرور و کلاینت.
