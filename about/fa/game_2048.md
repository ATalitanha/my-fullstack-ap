# مستندات بازی 2048

بازی 2048 یک بازی پازل عددی است که در آن بازیکن باید کاشی‌های با اعداد مشابه را با هم ترکیب کند تا به عدد 2048 برسد.

## پیاده‌سازی فنی

### 1. ساختار داده (`src/app/game/2048/page.tsx`)
کاشی‌ها به صورت یک آرایه از اشیاء `Tile` ذخیره می‌شوند:
```typescript
type Tile = {
  id: number;      // شناسه یکتا برای انیمیشن‌ها
  value: number;   // مقدار عددی کاشی
  row: number;     // ردیف (0-3)
  col: number;     // ستون (0-3)
};
```

### 2. منطق حرکت (`move`)
تابع `move` مسئول جابجایی و ترکیب کاشی‌هاست:
- کاشی‌ها بر اساس جهت حرکت مرتب می‌شوند تا پردازش درست انجام شود.
- برای هر کاشی، تا زمانی که به لبه جدول یا یک کاشی دیگر برخورد نکند، جابجا می‌شود.
- اگر دو کاشی با مقدار یکسان برخورد کنند، ترکیب شده و امتیاز بازیکن افزایش می‌یابد.
- پس از هر حرکت موفق، یک کاشی جدید (2 یا 4) در یک مکان خالی ایجاد می‌شود.

### 3. انیمیشن‌ها
از `framer-motion` برای ایجاد انیمیشن‌های روان استفاده شده است:
- `layoutId`: برای جابجایی نرم کاشی‌ها بین موقعیت‌های مختلف.
- `initial` و `animate`: برای انیمیشن بزرگ‌نمایی هنگام ظاهر شدن کاشی جدید.
- `AnimatePresence`: برای مدیریت خروج کاشی‌های ترکیب شده.

### 4. کنترل‌ها
بازیکن می‌تواند از کلیدهای جهت‌نما (Arrow Keys) یا کلیدهای `WASD` برای بازی استفاده کند.

## ویژگی‌ها
- **امتیازدهی**: ذخیره امتیاز فعلی و بهترین امتیاز (در `localStorage`).
- **پایان بازی**: نمایش پیام "Game Over" در صورت نبود حرکت ممکن.
- **برد**: نمایش پیام پیروزی هنگام رسیدن به عدد 2048.
- **طراحی مدرن**: استفاده از پالت رنگی هماهنگ با تم اپلیکیشن و افکت‌های بصری.
