# مستندات ابزارهای بهره‌وری

TanhaApp مجموعه‌ای از ابزارهای کاربردی را برای بهبود کارهای روزانه ارائه می‌دهد.

## 1. پیام‌رسان (Messenger)
سیستمی برای ارسال و مدیریت پیام‌های متنی.
- **API**: از `/api/massage` برای عملیات CRUD (ایجاد، خواندن، حذف) استفاده می‌کند.
- **ویژگی‌ها**: اعتبارسنجی فرم، حذف تکی و کلی پیام‌ها، انیمیشن‌های لیست.

## 2. لیست کارها (To-Do List)
مدیریت وظایف روزانه با قابلیت علامت‌گذاری به عنوان انجام شده.
- **احراز هویت**: برای دسترسی به این بخش، کاربر باید وارد حساب خود شده باشد.
- **تکنولوژی**: استفاده از Prisma برای ذخیره وظایف در پایگاه داده.
- **ویژگی‌ها**: ویرایش وظایف، فیلتر کردن کارهای باقی‌مانده، مودال‌های تایید.

## 3. یادداشت‌ها (Notes)
فضایی برای ثبت یادداشت‌های شخصی.
- **ساختار**: هر یادداشت شامل عنوان، محتوا و زمان ایجاد است.
- **امنیت**: یادداشت‌ها برای هر کاربر شخصی‌سازی شده‌اند و از طریق JWT محافظت می‌شوند.

## 4. جدول قیمت‌ها (Prices Table)
نمایش لحظه‌ای قیمت طلا، ارز و رمزارزها.
- **منبع داده**: دریافت داده‌ها از API خارجی (`brsapi.ir`).
- **قابلیت‌ها**: جستجوی سریع، دسته‌بندی بر اساس نوع دارایی، نمایش درصد تغییرات.

## 5. گنجینه داده (Data Repository)
ذخیره‌سازی فرمول‌های ریاضی و داده‌های علمی.
- **ویژگی خاص**: پشتیبانی از فرمت **LaTeX** برای نمایش زیبای فرمول‌های ریاضی با استفاده از `react-katex`.
- **مدیریت**: امکان تعریف دسته‌بندی و زیردسته‌های سفارشی.

## 6. ماشین‌حساب (Calculator)
شامل ماشین‌حساب ساده، پیشرفته و تبدیل واحد.
- **Advanced Calculator**: استفاده از کتابخانه `mathjs` برای محاسبات پیچیده علمی.
- **Unit Converter**: تبدیل واحدهای مختلف (طول، وزن، دما و غیره) با استفاده از منطق اختصاصی در `src/lib/converter.ts`.
